# Data files

Place these two files in `data/raw/` before running the notebook:

- `energy_dataset.csv`
- `weather_features.csv`

The project used the public Kaggle dataset [Hourly Energy Demand, Generation and Weather](https://www.kaggle.com/datasets/nicholasjhana/energy-consumption-generation-prices-and-weather), covering Spain from 2015 to 2018. Check the source page's current licence and the original data-provider terms before redistributing the raw files.

The repository intentionally excludes the data so that the code and project authorship remain separate from the dataset's licence.
